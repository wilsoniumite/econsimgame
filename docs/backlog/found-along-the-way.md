## What breaks play, or makes the picture say something untrue

1. **A real game is not lost to a test start.** A game started with `--advance` sets the island's own saved game aside, and four such starts can lose it (L120). Two copies of the game on one island write the same autosave and the later one wins (L121); for a moment while a new game sets the old one aside there is no latest save at all (L126). `--load` with no file after it takes the next flag for the file (C138); a save doctored to the year 5000 is accepted and played for 3,251 years (C139); nothing bounds the number of families a save or `--families` may name (L127). Never run through the real program: the refusal of a bad `--save` place and the `.unread` file, the card shown when an earlier save is used, and a whole century saved and loaded on the merged build (L128, L124, L122). And small autosaves dated 11 November in `%APPDATA%\Isolated State\saves` may be a helper's and not hers (L49). *Why:* the one piece here that can cost Stella a game she is playing. Hours, not days. *Trigger:* after `night/calendar` lands, which changes the save's layout, `saves.rs` and `live.rs`. *Reported:* the saved-games builder and reviewer, the viewer's integrator, the far view's housekeeping.
